# PayPal Agent Toolkit use

`PayPalReal` invokes the AI SDK tools directly, without a language model: it obtains
`toolkit.getTools()` and calls each tool's `execute(input)`. This is intentional: all
input is constructed and validated by application code, not generated by an LLM.

Toolkit evidence: `node_modules/@paypal/agent-toolkit/ai-sdk/index.js:1` defines each
AI SDK tool as `tool({ ..., execute: o => e.run(n, o) })`; the method switch includes
`create_invoice`, `get_invoice`, `send_invoice`, `generate_invoice_qr_code`, and
`record_payment_for_invoice` in the same package. The required configuration is
`{ actions: ALL_TOOLS_ENABLED, context: { sandbox: true } }`.

The real adapter is never selected unless `PAYPAL_ENVIRONMENT=SANDBOX`.

For F2, `PayPalReal.registrarPagoExterno` calls `record_payment_for_invoice` with
`invoice_id`, `method: "BANK_TRANSFER"`, `payment_date` and `amount` (currency code
and two-decimal value). The installed toolkit declares those fields and the allowed
method in `node_modules/@paypal/agent-toolkit/openai/index.mjs:290-299`; it builds the
request body from them in `node_modules/@paypal/agent-toolkit/openai/index.mjs:1379-1405`.
